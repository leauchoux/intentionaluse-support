MomenTap은 사용자가 직접 선택한 앱을 열기 전에 잠시 멈추고 지금 필요한 사용인지 확인하도록 돕습니다. 직접 선택한 웹사이트도 보호하며, MomenTap의 보호 탭에서 하나를 골라 5·10·15분 중 하나로 잠시 허용할 수 있습니다.

문제 해결

자주 묻는 질문

Shield가 표시되지 않아요
  1. MomenTap의 보호 탭에서 보호 상태가 켜짐인지 확인합니다.
  2. 선택 앱·웹사이트·카테고리 수가 1개 이상인지 확인합니다.
  3. Screen Time 권한이 승인 상태인지 확인합니다.
  4. 보호 설정에서 대상을 다시 저장하고 보호를 켭니다.
  5. 계속되지 않으면 iPhone을 재시동한 뒤 MomenTap을 한 번 엽니다.
카테고리 Shield에 사용 의도 확인 버튼이 없어요

정상 동작입니다. 카테고리 Shield에서는 MomenTap이 정확히 어떤 앱을 열었는지 안전하게 식별할 수 없어 닫기 버튼만 제공합니다. 임시 허용이 필요하면 앱을 개별 대상으로 선택하세요.

웹사이트에 앱과 같은 두 버튼이 없어요

정상 동작입니다. 선택한 웹사이트는 Safari에서 Apple의 기본 제한됨 화면과 확인 버튼으로 표시되며, 이 화면에는 MomenTap의 사용자 지정 두 버튼이 나타나지 않습니다. 잠시 접속하려면 MomenTap의 보호 탭에서 웹사이트 잠시 허용을 선택하고, 직접 선택한 웹사이트 하나와 목적을 설정한 뒤 5·10·15분 중 하나를 고르세요. 브라우저는 자동으로 열리지 않으므로 허용을 시작한 뒤 직접 돌아가야 합니다. 허용한 웹사이트 하나 외의 선택 웹사이트와 카테고리는 계속 보호되며 웹사이트별 선택 기록은 제공하지 않습니다. Apple의 공개 API 특성상 모든 서브도메인과 브라우저에서 같은 동작을 보장하지 않습니다.

개별 앱 Shield에서 MomenTap이 열리지 않아요

MomenTap은 iOS 26.5 이상을 지원합니다. 지원되는 iPhone에서 개별 앱 Shield의 할 일이 있어요를 선택하면 MomenTap의 목적·허용 시간 설정 화면으로 이동합니다.

허용 시간이 끝났는데 Shield가 바로 보이지 않아요

iOS가 백그라운드 작업의 실행 시각을 결정하므로 짧은 지연이 생길 수 있습니다. 대상 앱을 다시 열어 확인하고, 계속 보호되지 않으면 MomenTap을 열어 상태를 다시 확인하세요.

모든 앱 데이터를 초기화하면 Screen Time 권한도 사라지나요?

아니요. 초기화는 MomenTap이 저장한 앱·웹사이트·카테고리 선택, Shield 요청, 임시 허용, 세션, Live Activity, 전체 선택 기록과 앱별 token 연결을 정리하지만 시스템의 Screen Time 권한 자체는 철회하지 않습니다. 이전 시험 버전의 웹사이트별 기록 연결도 함께 정리합니다. 권한은 iPhone 설정에서 별도로 철회할 수 있습니다.

어떤 선택 기록이 저장되나요?

기록은 기본적으로 꺼져 있습니다. 기기 내 선택 기록을 켜면 대상 식별 정보 없이 의도적 임시 허용과 습관적 실행 중단의 시각·종료 사유를 이 iPhone에 최대 90일 보관합니다. 앱별 선택 기록은 별도로 동의해야 하며, 동의 뒤 새로 발생한 앱 선택만 무작위 참조와 별도 불투명 application token 인덱스로 구분합니다. 앱 이름은 저장하지 않고 Apple 시스템 UI가 표시합니다. 웹사이트별 기록, 카테고리, 입력한 목적과 원시 Screen Time 사용량은 기록하지 않습니다.

총 허용 시간은 실제 앱 사용 시간인가요?

아니요. 총 허용 시간은 MomenTap이 Shield를 잠시 풀어 둔 시간입니다. 대상 앱을 실제로 화면에서 사용한 시간이나 다른 앱의 Screen Time 사용량을 수집한 값이 아닙니다.
