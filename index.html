문제 해결

자주 묻는 질문

Shield가 표시되지 않아요
  1. IntentionalUse 홈의 보호 상태가 켜짐인지 확인합니다.
  2. 선택 앱·카테고리 수가 1개 이상인지 확인합니다.
  3. Screen Time 권한이 승인 상태인지 확인합니다.
  4. 보호 설정에서 대상을 다시 저장하고 보호를 켭니다.
  5. 계속되지 않으면 iPhone을 재시동한 뒤 IntentionalUse를 한 번 엽니다.
카테고리 Shield에 사용 의도 확인 버튼이 없어요

정상 동작입니다. 카테고리 Shield에서는 IntentionalUse가 정확히 어떤 앱을 열었는지 안전하게 식별할 수 없어 닫기 버튼만 제공합니다. 임시 허용이 필요하면 앱을 개별 대상으로 선택하세요.

개별 앱 Shield에서 IntentionalUse가 열리지 않아요

Shield에서 IntentionalUse를 바로 여는 기능은 iOS 26.5 이상에서 제공됩니다. 이전 iOS에서는 Shield를 닫고 IntentionalUse를 직접 열어야 합니다.

허용 시간이 끝났는데 Shield가 바로 보이지 않아요

iOS가 백그라운드 작업의 실행 시각을 결정하므로 짧은 지연이 생길 수 있습니다. 대상 앱을 다시 열어 확인하고, 계속 보호되지 않으면 IntentionalUse를 열어 상태를 다시 확인하세요.

모든 앱 데이터를 초기화하면 Screen Time 권한도 사라지나요?

아니요. 초기화는 IntentionalUse가 저장한 선택, 임시 허용, 세션과 Live Activity를 정리하지만 시스템의 Screen Time 권한 자체는 철회하지 않습니다. 권한은 iPhone 설정에서 별도로 철회할 수 있습니다.

어떤 선택 기록이 저장되나요?

기록은 기본적으로 꺼져 있습니다. 사용자가 켜면 의도적 임시 허용과 습관적 실행 중단의 시각·종료 사유를 이 iPhone에 최대 90일 보관합니다. 앱별 기록에도 동의하면 무작위 참조와 별도 불투명 application token 인덱스로 허용·멈춤 횟수를 앱별로 나눕니다. 앱 이름은 저장하지 않고 Apple 시스템 UI가 표시하며, 카테고리·입력한 목적·원시 Screen Time 사용량은 기록하지 않습니다.

총 허용 시간은 실제 앱 사용 시간인가요?

아니요. 총 허용 시간은 IntentionalUse가 Shield를 잠시 풀어 둔 시간입니다. 대상 앱을 실제로 화면에서 사용한 시간이나 다른 앱의 Screen Time 사용량을 수집한 값이 아닙니다.
